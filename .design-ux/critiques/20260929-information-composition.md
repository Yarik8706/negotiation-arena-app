# Критика композиции

Вердикт: accept после корректировок.

Приняты: удаление дублирующего бокового меню, вопросы и реплики в справочнике, строки кейсов, единое имя участника, публичное досье игрока, эпизоды до вторичных баллов отчёта.

Исправлено при проверке: hardcoded светлые поверхности и имя оппонента в dark; недостаточный контраст primary-action текста; переполнение навигации на 800px; декоративные полосы статистики; ошибочное скругление журнальных разделителей.

Отклонено как вне текущего diff: удаление bootstrap-icons (зависимость уже была в working tree до задания), откат чужих data/attempts.json, изменение существующей обработки ошибки restart. В этом проходе новые зависимости не добавлены. Действия и API не заменены.

Ограничения: успешный повтор проверен; сбой создания повтора сохраняет прежнее поведение. Headless-проверка не подтверждает звук и реальные разрешения микрофона. Боевой многопользовательский режим не проверен.
