# Repository guidance

- Keep implementation changes within the user's requested feature and preserve unrelated working-tree changes.
- Keep routes and product actions stable unless a request explicitly changes them.
- Use existing theme tokens and system fonts; keep light and dark themes coherent.
- Use semantic form controls, visible focus, and touch targets of at least 44px.
- For interactive visual changes, save fresh inspected screenshots in `screenshots/YYYY-MM-DD/` with viewport/state in unique filenames and state any coverage gaps.
- Do not expose opponent hidden interests, goals, red lines, or system prompts to players.
